# Guess Its Size - план интерфейса (черновик)

Правила игры описаны в `GAME_DESIGN.md`. Здесь только интерфейс: какие
экраны есть, что на каждом из них и как они сменяют друг друга.

Пометки те же:

- **[Решено]** - уже решено в `GAME_DESIGN.md` или твоими ответами.
- **[Предложение]** - моё предложение, нужно твоё "да" или "нет".
- **[Открыто]** - тебе ещё нужно выбрать.

Текст на макетах написан по-английски - так, как он будет выглядеть в игре.

---

## 1. Общие принципы [Решено]

- **Сначала телефон.** Большинство игроков Roblox играют с телефона, поэтому
  кнопки крупные, ползунок широкий, а важное не прячется в углах.
- **Верхний левый угол свободен** - там кнопки меню и чата самого Roblox.
- **Размеры в процентах экрана** (Scale), а не в пикселях, чтобы интерфейс
  одинаково выглядел на телефоне, планшете и компьютере.
- **Язык** - английский. Roblox сам переводит интерфейс для игроков из
  других стран.
- **Минимум надписей.** Что происходит, показывают анимации и эффекты, а не
  текст.
- **Цвет игрока**: у каждого места за столом свой цвет. Этим цветом
  окрашены его карточка, его догадка и его имя.

| Что                  | Цвет                         |
|----------------------|------------------------------|
| Игрок 1              | синий                        |
| Игрок 2              | красный                      |
| Игрок 3              | зелёный                      |
| Игрок 4              | жёлтый                       |
| Настоящий размер     | белый                        |
| Кубок, наличные      | золотой                      |
| Сердца               | красные, потерянные - серые  |
| Кнопка LOCK IN       | красная                      |
| Панели               | тёмные, полупрозрачные       |

## 3. Экраны

### 3.1 HUD - кубки и наличные [Решено]

Всегда на экране - и в лобби, и за столом.

```
+------------------------------------------------------------+
| (меню Roblox)                                              |
|                                                            |
|                                                            |
|                   (игрок ходит по лобби)                   |
|                                                            |
|                                                            |
|  12 🏆                                                     |
|  1 250 💵                                                  |
+------------------------------------------------------------+
```

- Снизу слева: число кубков, под ним - наличные.
- Сюда прилетают награды в конце матча (раздел 3.7).
- [Открыто] На телефоне снизу слева находится джойстик Roblox для
  ходьбы - счётчики будут под пальцем. Моё предложение: на телефоне
  поднять их чуть выше, над зоной джойстика.

### 3.2 Ожидание за столом [Решено]

Входа через меню нет: игрок подходит к стулу или запрыгивает на него и
сразу садится.

```
+------------------------------------------------------------+
|                                                            |
|                                                            |
|                                                            |
|                                                            |
|               Waiting for players... 2/4                   |
|                                                            |
|  12 🏆                                                     |
|  1 250 💵                                                  |
+------------------------------------------------------------+
```

Когда игроков достаточно (1v1 - 2, 4P - 3 или 4), надпись меняется на
отсчёт:

```
                      Starting in 5
```

- Кнопки "Leave" нет. Выйти можно только прыжком - и только до конца
  отсчёта. Игрок остаётся стоять рядом со стулом.

### 3.3 HUD матча - карточки игроков [Решено]

Во время матча сверху видны карточки игроков: аватар, имя, сердца. Номера
раунда нет.

Стол на 4 игрока:

```
 [аватар] Anna   [аватар] Ben    [аватар] Cat   [аватар] Dan
 ♥ ♥ ♥ ♥         ♥ ♥ ♥ ♡         ♥ ♥ ♡ ♡        ♥ ♥ ♥ ♥
```

Стол 1 на 1 - карточки слева и справа, "VS" по центру:

```
 [аватар] Anna                                 Ben [аватар]
 ♥ ♥ ♥ ♥ ♥                  VS                  ♥ ♥ ♥ ♡ ♡
```

- ♥ - красное сердце, ♡ - потерянное, **серое**. В игре это картинки.
- Рамка карточки - цвета игрока.
- Если за столом на 4 игрока сели трое, карточек три.

### 3.4 Угадывание (до 30 с) [Решено]

Появляется сразу после отсчёта и сразу после каждого раскрытия - без
заставок и номеров раундов.

```
+------------------------------------------------------------+
|  (карточки игроков)          25                            |
|                                                            |
|        ___                                                 |
|       |   |          /\                                    |
|       | R |         /  \     <- твоя догадка (твой цвет)   |
|       |___|        /____\                                  |
|   ================================ сцена                   |
|                                                            |
|  Door (height 2.0 m)       Giraffe - guess the HEIGHT      |
|  smaller <=============|=================> bigger          |
|                         5.2 m                             |
|  12 🏆                                      [ LOCK IN ]   |
|  1 250 💵                                   (красная)     |
+------------------------------------------------------------+
```

- Ползунок без делений - только "smaller" / "bigger".
- Под ползунком - догадка в **cm, m или km**, смотря какой размер
  (правило в `GAME_DESIGN.md`, раздел 4).
- Слово HEIGHT или LENGTH выделено цветом.
- Таймер - крупное число сверху по центру; последние 5 секунд оно красное.
- Камера неподвижна и смотрит на эталон и твою догадку. Когда картинка
  растёт или уменьшается, камера сама отъезжает, чтобы всё помещалось.
- Управление:

| Устройство | Ползунок                         | LOCK IN         |
|------------|----------------------------------|-----------------|
| Телефон    | тянуть пальцем                   | кнопка          |
| Компьютер  | мышь или стрелки влево/вправо    | кнопка или Enter|
| Консоль    | левый стик                       | кнопка A        |

### 3.5 Picking... [Решено]

После LOCK IN ползунок и кнопка исчезают. На экране только одна надпись -
отсчёт до раскрытия в секундах:

```
+------------------------------------------------------------+
|  (карточки игроков)                                        |
|                                                            |
|                                                            |
|                    Picking... (18)                         |
|                                                            |
|  12 🏆                                                     |
|  1 250 💵                                                  |
+------------------------------------------------------------+
```

### 3.6 Раскрытие ответа (5 с) [Решено]

Камера поднимается над столом, чтобы были видны догадки всех игроков.

```
+------------------------------------------------------------+
|  (карточки игроков)                                        |
|                                                            |
|                      Ben   91.40%                          |
|                         [догадка]                          |
|                                                            |
|  Anna  78.05%     +----------------+     Cat  99.12%       |
|    [догадка]      | Actual: 5.2 m  |       [догадка]       |
|                   |   [настоящий]  |    (радужная, светится)|
|                   +----------------+                       |
|                                                            |
|                      Dan   64.33%                          |
|                         [догадка]                          |
|                  (Dan - эффект удара)                      |
+------------------------------------------------------------+
```

Порядок анимации:

1. Все догадки появляются одновременно - каждая перед своим игроком.
2. Настоящий объект вырастает до реального размера относительно эталона.
3. Проценты "набегают" от 0 до итогового числа рядом с каждой догадкой.
4. Худший игрок: по его персонажу проходит **эффект удара, как у Стива в
   Minecraft** - короткая красная вспышка, толчок и звук удара. Одно
   сердце на его карточке становится серым. Надписей нет.
5. Лучшая догадка немного выделяется (например, чуть толще контур и
   чуть крупнее процент). Если точность **99% и выше** - догадка
   переливается цветами радуги и слегка светится.

### 3.7 Выбывание [Решено]

Отдельного экрана нет.

- Когда у игрока забирают последнее сердце: эффект удара, и сразу, без
  предупреждения, его **высаживают рядом со стулом**.
- Если за его место положены наличные, из центра экрана вылетает
  **+N 💵** и улетает в счётчик снизу слева.
- Карточка выбывшего остаётся сверху - все сердца серые.

### 3.8 Конец матча [Решено]

Никаких надписей и кнопок.

```
+------------------------------------------------------------+
|                                                            |
|                                                            |
|                         +1 🏆                              |
|                        +150 💵                             |
|                     /                                      |
|                  /     (летят вниз влево)                  |
|  12 🏆 <-                                                  |
|  1 250 💵 <-                                               |
+------------------------------------------------------------+
```

- Победитель остаётся сидеть на стуле.
- Из центра экрана вылетает **+1 🏆**, за ним **+N 💵**; оба улетают в
  счётчики снизу слева, и числа в счётчиках увеличиваются.
- После этого стол снова ждёт игроков ("Waiting for players... 1/4"), а
  победитель уже сидит за ним.

### 3.9 Доска "Top winners 🏆" в лобби [Решено]

Настоящая доска в мире лобби (SurfaceGui).

```
+----------------------------------------+
|             Top winners 🏆             |
|----------------------------------------|
|  1  [аватар]  Cat .............  248   |
|  2  [аватар]  Ben .............  201   |
|  3  [аватар]  Anna ............  187   |
|  ...                                   |
| 10  [аватар]  Eve .............   64   |
+----------------------------------------+
```

- Первые три места - золотая, серебряная и бронзовая рамка.
- Доска обновляется раз в несколько минут.

## 4. Мелкие правила [Решено]

- Прыжок работает как выход со стула только до конца отсчёта. После этого
  прыжок отключён, пока игрок в матче.
- Все надписи крупные и с тёмной обводкой, чтобы читались на любом фоне.
- Звуки: тик таймера в последние 5 секунд, щелчок при LOCK IN, звук удара
  у худшего, фанфары при победе.

## 5. Как это устроено в Roblox [Решено]

| ScreenGui / объект | Где                   | Что показывает                             |
|--------------------|-----------------------|--------------------------------------------|
| CounterHUD         | StarterGui            | 🏆 и 💵 снизу слева                        |
| TableWaitUI        | StarterGui            | "Waiting for players...", "Starting in 5"  |
| MatchHUD           | StarterGui            | Карточки игроков, сердца, таймер           |
| GuessUI            | StarterGui            | Ползунок, единицы, LOCK IN, "Picking..."   |
| RewardUI           | StarterGui            | Вылетающие +1 🏆 / +N 💵                   |
| BillboardGui       | над панелями догадок  | Имя игрока и процент                       |
| SurfaceGui         | доска в лобби         | "Top winners 🏆"                           |
| Seat               | у каждого места       | Сел - вошёл, прыгнул - вышел               |
| Highlight          | на персонаже          | Красная вспышка эффекта удара              |

- Анимации - через TweenService.
- Радужная догадка - цвет панели плавно меняется по кругу
  (Color3.fromHSV), плюс слабое свечение (PointLight или Highlight).
- Аватары в карточках - через Players:GetUserThumbnailAsync.
- Камера во время матча - Scriptable, ей управляет скрипт StageView.
- После конца отсчёта сервер ставит игрокам за столом JumpHeight = 0,
  чтобы прыжок не поднимал их со стула.
- Высадка выбывшего: сервер снимает его со стула и ставит персонажа рядом
  со стулом.
- У всех ScreenGui ResetOnSpawn = false, чтобы интерфейс не пропадал.
