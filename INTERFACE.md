# Guess Its Size - план интерфейса (черновик)

Правила игры описаны в `GAME_DESIGN.md`. Здесь только интерфейс: какие
экраны есть, что на каждом из них и как они сменяют друг друга.

Пометки те же:

- **[Решено]** - уже решено в `GAME_DESIGN.md` или твоими ответами.
- **[Предложение]** - моё предложение, нужно твоё "да" или "нет".
- **[Открыто]** - тебе ещё нужно выбрать.

Текст на макетах написан по-английски - так, как он будет выглядеть в игре
(см. раздел 1, пункт "Язык").

---

## 1. Общие принципы [Предложение]

- **Сначала телефон.** Большинство игроков Roblox играют с телефона, поэтому
  кнопки крупные, ползунок широкий, а важное не прячется в углах.
- **Верхний левый угол свободен** - там кнопки меню и чата самого Roblox.
- **Размеры в процентах экрана** (Scale), а не в пикселях, чтобы интерфейс
  одинаково выглядел на телефоне, планшете и компьютере.
- **Язык** [Открыто]: весь текст в игре на английском ("Picking...",
  "Golden Cup", "Lock In"). Roblox сам переводит интерфейс для игроков из
  других стран.
- **Цвет игрока**: у каждого места за столом свой цвет. Этим цветом
  окрашены его карточка, его догадка и его имя.

| Что                  | Цвет                         |
|----------------------|------------------------------|
| Игрок 1              | синий                        |
| Игрок 2              | красный                      |
| Игрок 3              | зелёный                      |
| Игрок 4              | жёлтый                       |
| Настоящий размер     | белый                        |
| Кубок, наличные      | золотой                      |
| Сердца               | красные                      |
| Панели               | тёмные, полупрозрачные       |

## 3. Экраны

### 3.1 Лобби - HUD [Предложение]

Постоянно на экране, пока игрок в лобби.

```
+------------------------------------------------------------+
| (меню Roblox)                     [ Cash 1 250 ]           |
|                                   [ Cups    12 ]           |
|                                                            |
|                                                            |
|                   (игрок ходит по лобби)                   |
|                                                            |
|                                                            |
|                      [ E  Join 1v1 ]                       |
|                                                            |
+------------------------------------------------------------+
```

- Справа сверху - наличные и число золотых кубков.
- Подсказка "Join 1v1" / "Join 4P" появляется, когда игрок подходит к
  свободному месту (ProximityPrompt). На телефоне это кнопка, на
  компьютере - клавиша E.

### 3.2 Ожидание за столом [Предложение]

```
+------------------------------------------------------------+
|                                   [ Cash 1 250 ]           |
|                                   [ Cups    12 ]           |
|                                                            |
|                                                            |
|                                                            |
|            +--------------------------------+              |
|            |  4P TABLE                      |              |
|            |  Waiting for players...  2/4   |              |
|            |                    [ Leave ]   |              |
|            +--------------------------------+              |
+------------------------------------------------------------+
```

Когда все места заняты, панель меняется на большой отсчёт по центру:

```
                     Starting in 5
```

- "Leave" поднимает игрока с места и возвращает в лобби.

### 3.3 HUD матча - всегда сверху [Предложение]

Во время матча сверху всегда видны карточки игроков: аватар, имя, сердца.

Стол на 4 игрока:

```
 [аватар] Anna   [аватар] Ben    [аватар] Cat   [аватар] Dan
 <3 <3 <3 <3     <3 <3 <3 --     <3 <3 -- --    <3 <3 <3 <3

                          ROUND 3
```

Стол 1 на 1 - карточки слева и справа, "VS" по центру:

```
 [аватар] Anna                                 Ben [аватар]
 <3 <3 <3 <3 <3           ROUND 3           <3 <3 <3 -- --
                             VS
```

- `<3` - целое сердце, `--` - потерянное. В игре это картинки сердец.
- Рамка карточки - цвета игрока.
- Выбывший игрок - серая карточка с крестиком.

### 3.4 Начало раунда (3 с) [Предложение]

Баннер по центру поверх сцены.

```
+------------------------------------------------------------+
|  (HUD матча)                                               |
|                                                            |
|            +--------------------------------+              |
|            |           ROUND 3              |              |
|            |                                |              |
|            |  Reference: Door (height 2.0 m)|              |
|            |  Guess the HEIGHT of:          |              |
|            |          GIRAFFE               |              |
|            +--------------------------------+              |
|                                                            |
+------------------------------------------------------------+
```

- Слово HEIGHT или LENGTH выделено цветом, чтобы его нельзя было
  пропустить.

### 3.5 Угадывание (до 30 с) [Решено + Предложение]

```
+------------------------------------------------------------+
|  (HUD матча)                 25                            |
|                                                            |
|        ___                                                 |
|       |   |          /\                                    |
|       | R |         /  \     <- твоя догадка (твой цвет)   |
|       |___|        /____\                                  |
|   ================================ сцена                   |
|                                                            |
|  Giraffe - guess the HEIGHT               5.2 m            |
|  smaller <=============|=================> bigger          |
|                                             [ LOCK IN ]   |
+------------------------------------------------------------+
```

- [Решено] Ползунок без делений - только "smaller" / "bigger". Под ним
  догадка в метрах.
- [Предложение] Таймер - крупное число сверху по центру. Последние 5 секунд
  оно красное.
- [Предложение] Камера неподвижна и смотрит на эталон и твою догадку.
  Картинка меняет размер вместе с ползунком, а камера сама отъезжает, чтобы
  объект помещался на экране.
- [Предложение] Управление:

| Устройство | Ползунок                         | Lock In         |
|------------|----------------------------------|-----------------|
| Телефон    | тянуть пальцем                   | кнопка          |
| Компьютер  | мышь или стрелки влево/вправо    | кнопка или Enter|
| Консоль    | левый стик                       | кнопка A        |

### 3.6 Picking... - ждём остальных [Решено]

После "Lock In" нижняя панель меняется:

```
|                                                            |
|  Giraffe - your guess: 5.2 m  (locked)                     |
|                                                            |
|                    Picking... (18)                         |
+------------------------------------------------------------+
```

- Число в скобках - секунды до конца таймера.
- Если все зафиксировали ответ раньше, сразу начинается раскрытие.

### 3.7 Раскрытие ответа (5 с) [Решено + Предложение]

Камера поднимается над столом, чтобы были видны догадки всех игроков.

```
+------------------------------------------------------------+
|  (HUD матча)                                               |
|                                                            |
|                      Ben   91.40%                          |
|                         [догадка]                          |
|                                                            |
|  Anna  78.05%     +----------------+     Cat  99.12%       |
|    [догадка]      | Actual: 5.2 m  |       [догадка]       |
|                   |   [настоящий]  |        BEST           |
|                   +----------------+                       |
|                                                            |
|                      Dan   64.33%                          |
|                         [догадка]                          |
|                      -1 heart                              |
+------------------------------------------------------------+
```

- [Решено] Проценты - рядом с догадкой каждого игрока, не над головой.
- [Решено] Худшая догадка теряет сердце, у лучшей ничего не происходит.
- [Предложение] Порядок анимации:
  1. Все догадки появляются одновременно.
  2. Настоящий объект вырастает до реального размера.
  3. Проценты "набегают" от 0 до итогового числа.
  4. Худшая догадка мигает красным, на её карточке сверху разбивается
     сердце, появляется надпись "-1 heart".
  5. Лучшая догадка получает надпись "BEST" (только надпись, без награды).

### 3.8 Выбыл - режим зрителя [Предложение]

```
+------------------------------------------------------------+
|  (HUD матча - твоя карточка серая)                         |
|                                                            |
|                                                            |
|                    YOU'RE OUT!                             |
|                    Spectating...                           |
|                                                            |
|                                             [ Leave ]     |
+------------------------------------------------------------+
```

- Игрок остаётся за столом и смотрит раунды дальше, но без ползунка.
- "Leave" - вернуться в лобби сразу.

### 3.9 Конец матча [Решено + Предложение]

Победитель:

```
+------------------------------------------------------------+
|                                                            |
|                      [ картинка                            |
|                      золотого кубка ]                      |
|                                                            |
|                        YOU WON!                            |
|                      +150 Cash                             |
|                   Golden Cups: 13                          |
|                                                            |
|              [ Play Again ]     [ Leave ]                  |
+------------------------------------------------------------+
```

Остальные:

```
+------------------------------------------------------------+
|                                                            |
|                   Winner: Cat                              |
|              [ маленький золотой кубок ]                   |
|                                                            |
|                     Your place: 3rd                        |
|                                                            |
|              [ Play Again ]     [ Leave ]                  |
+------------------------------------------------------------+
```

- [Решено] Картинка золотого кубка - знак победы в матче.
- [Предложение] Наличные и кубки "набегают" в счётчиках HUD.
- [Предложение] "Play Again" - остаться за столом и ждать новый матч.
  "Leave" - встать и вернуться в лобби.

### 3.10 Доска Golden Cup в лобби [Решено + Предложение]

Настоящая доска в мире лобби (SurfaceGui).

```
+----------------------------------------+
|             GOLDEN CUP                 |
|           (картинка кубка)             |
|----------------------------------------|
|  1  [аватар]  Cat .............  248   |
|  2  [аватар]  Ben .............  201   |
|  3  [аватар]  Anna ............  187   |
|  ...                                   |
| 10  [аватар]  Eve .............   64   |
+----------------------------------------+
```

- [Предложение] Первые три места - золотая, серебряная и бронзовая рамка.
- [Предложение] Доска обновляется раз в несколько минут (так работают
  OrderedDataStore в Roblox).

## 4. Мелкие правила [Предложение]

- Во время матча прыжок отключён: в Roblox прыжок поднимает игрока с места,
  и он бы случайно вышел из матча. Выйти можно только кнопкой "Leave".
- Все надписи крупные и с тёмной обводкой, чтобы читались на любом фоне.
- Звуки: тик таймера в последние 5 секунд, "щелчок" при Lock In, звук
  разбитого сердца, фанфары при победе.

## 5. Как это устроено в Roblox [Предложение]

| ScreenGui / объект | Где                  | Что показывает                            |
|--------------------|----------------------|-------------------------------------------|
| LobbyHUD           | StarterGui           | Наличные, кубки                           |
| TableWaitUI        | StarterGui           | Ожидание, отсчёт, "Leave"                 |
| MatchHUD           | StarterGui           | Карточки игроков, сердца, раунд, таймер   |
| RoundBanner        | StarterGui           | Баннер начала раунда                      |
| GuessUI            | StarterGui           | Ползунок, метры, "Lock In", "Picking..."  |
| ResultUI           | StarterGui           | Выбыл, конец матча, кубок                 |
| BillboardGui       | над панелями догадок | Имя игрока и процент                      |
| SurfaceGui         | доска в лобби        | Список Golden Cup                         |
| ProximityPrompt    | у каждого места      | "Join 1v1" / "Join 4P"                    |

- Анимации - через TweenService.
- Аватары в карточках - через Players:GetUserThumbnailAsync.
- Камера во время матча - Scriptable, ей управляет скрипт StageView.
- У всех ScreenGui ResetOnSpawn = false, чтобы интерфейс не пропадал.
