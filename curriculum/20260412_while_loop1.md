## 1. Diamond of asterisks

Input the number of lines (must be odd; 0 exits; anything even and nonzero is invalid).

```
Please input the number of lines:7
    *
   ***
  *****
*********
  *****
   ***
*
Please input the number of lines:6
Input valid! It should be an odd number!
Please input the number of lines:5
    *
   ***
  *****
   ***
    *
Please input the number of lines:0
Exit!!!!
```

## 2. Repunit-style sum

Output the result of `2 + 22 + 222 + 2222 + ... + 22...2` (n twos in the last term). The number of digits in the last term is input by the user.

## 3. Digit sum vs. digit product filter

Output all numbers between 100 and 2000 where the sum of all its digits is greater than the product of all its digits.

Example: given 477 — ones place 7, tens place 7, hundreds place 4. Sum = 7+7+4 = 18. Product = 7×7×4 = 196.
