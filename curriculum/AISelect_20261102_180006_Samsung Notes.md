# Handwritten note — cross product (screenshot)

Companion to `AISelect_20261102_180006_Samsung Notes.jpg` (a cropped
Samsung Notes screenshot, 2026-11-02; arrived in the same zip as the
Chapter 24 slides). Phone metadata (EXIF) was stripped. No names or
personal details in the image.

Content: part "a) 1)", a vector (cross) product of (6, 0, −2) × (0, 8, 0),
worked as a 3×3 determinant expanded along the î ĵ k̂ row:

    | î  ĵ  k̂ |
    | 6  0 −2 |  =  |0 −2| î  −  |6 −2| ĵ  +  |6 0| k̂
    | 0  8  0 |     |8  0|       |0  0|       |0 8|

    written: = 16î − 0ĵ − 48k̂ = ⟨16, 0, 48⟩

Check: the 2×2 minors are 0·0 − (−2)(8) = 16, 6·0 − (−2)(0) = 0 and
6·8 − 0·0 = 48. The k̂ term carries a + sign in the expansion, so the
middle line should read +48k̂. The final vector ⟨16, 0, 48⟩ is correct;
only the sign in the middle line is a slip.
