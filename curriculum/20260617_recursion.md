## Comprehensive practice

Read positive integers into array `a` until the user enters -1. Save all the prime numbers of `a` into another array `b`. Output the sorted prime numbers of `b`.

```
Input:  3 5 1 13 78 93 2 11 4 9 7 -1
Output: 2 3 5 7 9 11 13
```

**Note:** 9 is not prime, so the worksheet's own sample output above looks like it contains a typo (or is testing something subtle). Don't let this derail the lesson — teach correct primality logic, and flag the discrepancy if Wifey notices it too.
