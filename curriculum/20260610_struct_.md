## 3. Student Grade Ranking System (main task)

Write a C++ program that records student information, computes averages, and outputs a ranking.

### Struct definition

```cpp
struct Student {
    int id;
    char name[...];   // cstring
    int score1, score2, score3;   // array
    double average;   // computed and stored
};
```

### Core functions

1. Input students' information.
2. Sort all students descending by average score. If averages tie, sort by student ID ascending.

### Added functions

1. Compute and output the class average for each of the three courses.
2. Find the student with the highest average; output their ID, name, average.
3. Output all students whose average is below 60 (ID, name, average). If none, output "None".

### Sample input

```
41001 Zhang 85 90 92
1002 Li 55 60 65
1003 Wang 90 95 88
1004 Zhao 40 50 45
```

(Note: the worksheet's own first ID looks like a typo — `41001` — likely meant `1001`.)

### Sample output (corrected)

```
1003 Wang 91.00
1001 Zhang 89.00
1002 Li 60.00
1004 Zhao 45.00
Course averages: 67.50 73.75 72.50
Highest average student: 1003 Wang 91.00
Average below 60: 1004 Zhao 45.00
```

### Optional challenge

If any score is negative or >100, mark that student's average as `-1.00`. When sorting, place all valid students (average ≥0) before invalid ones (order among invalid students doesn't matter). Exclude invalid students from course averages, from the "highest average" search, and from the "below 60" list.
