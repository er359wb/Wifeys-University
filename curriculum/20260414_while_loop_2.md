## 2. Armstrong Number

Determine if a given positive integer *n* is an Armstrong number (a number equal to the sum of its own digits, each raised to the power of the number of digits).

Examples:
- 153 = 1³+5³+3³ = 1+125+27 (3 digits, each cubed)
- 1634 = 1⁴+6⁴+3⁴+4⁴ (4 digits, each raised to the 4th power)

Print the sum, then "Yes" if it is an Armstrong number, otherwise "No".

| Input | Output |
|---|---|
| 153 | 153 YES |
| 2478 | 6769 No |
| 12345 | 4425 NO |
