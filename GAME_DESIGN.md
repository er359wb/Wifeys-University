# Guess Its Size - дизайн игры для Roblox (черновик)

Название рабочее. Каждый раздел помечен:

- **[Решено]** - взято прямо из твоей идеи или твоих ответов.
- **[Предложение]** - моё предложение, нужно твоё "да" или "нет".
- **[Открыто]** - тебе ещё нужно выбрать.

---

## 1. Основная идея [Решено]

Многопользовательская игра на угадывание высоты в стиле Magnitudle /
"Size It Up". В каждом раунде показывается **эталонный объект**, высоту
которого все знают, и **загадочный объект**. Игроки угадывают, какой высоты
загадочный объект, масштабируя его относительно эталона. Игрок, чья догадка
**точнее всех**, выигрывает раунд.

Есть два типа столов:

- **Стол 1 на 1** - дуэль двух игроков.
- **Стол на 4 игрока** - соревнуются четыре игрока.

Выбывание работает на **сердцах** (см. раздел 6).

Все объекты - **2D-картинки** (см. раздел 7).

### Референс: Size It Up

Сайт служит только ориентиром - копировать его внешний вид не нужно. Что в
нём есть:

- Эталон (например, зебра) и загадочный объект стоят рядом на одной линии
  земли; оба - плоские одноцветные силуэты.
- Игрок тянет загадочный силуэт за угол, меняя его размер, и нажимает
  "Lock In".
- После ответа показывается результат: "Your Answer: 1.908 m",
  "Actual: 3 m", "Off by 36%", а настоящий размер появляется серым силуэтом
  позади догадки.

## 2. Как это выглядит

### 2.1 Лобби [Предложение]

Один общий мир с настоящими столами. Игрок подходит и садится, чтобы
присоединиться, - никаких меню для поиска игры.

```
+-----------------------------------------------------------+
|                         ЛОББИ                             |
|                                                           |
|   [1v1]     [1v1]     [1v1]          +-----------+        |
|   o---o     o---o     o---o          | ТАБЛИЦА   |        |
|                                      | ЛИДЕРОВ   |        |
|                                      +-----------+        |
|      o               o                                    |
|    o[4P]o          o[4P]o          (точка появления)      |
|      o               o                                    |
|                                                           |
+-----------------------------------------------------------+
  o = место     [1v1] = стол на 2 места     [4P] = стол на 4 места
```

- Когда все места за столом заняты, начинается обратный отсчёт (например,
  5 секунд).
- Если кто-то встаёт во время отсчёта, он отменяется.

### 2.2 Стол и сцена [Решено]

В центре стола стоят эталон и настоящий объект. Перед **каждым игроком**
стоит его собственная догадка - та же картинка того размера, который он
выбрал, - с его процентом точности. Все игроки видят догадки всех.

Вид сверху, стол на 4 игрока (во время раскрытия ответа):

```
                         [ Игрок 2 ]
                     догадка 2: 91,40%

   [ Игрок 1 ]        +-------------+        [ Игрок 3 ]
  догадка 1: 78,05%   | эталон +    |   догадка 3: 99,12%
                      | настоящий   |     (лучший - ничего)
                      | объект      |
                      +-------------+

                     догадка 4: 64,33%
                     (худший: -1 сердце)
                         [ Игрок 4 ]
```

Стол 1 на 1 устроен так же, только с двумя местами друг напротив друга.

- [Предложение] Пока идёт угадывание, догадки соперников скрыты - видна
  только своя. Все догадки открываются одновременно при раскрытии.

### 2.3 Экран угадывания (у каждого игрока) [Решено]

```
+---------------------------------------------------------+
|  Раунд 3                  Сердца: 4/5       Время: 25   |
|                                                         |
|  Эталон:   Дверь  (2,0 м)                               |
|  Загадка:  Жираф                                        |
|                                                         |
|     [ вид камеры на эталон и твою догадку ]             |
|                                                         |
|  меньше <===========|===========================> больше|
|                                                         |
|  Твоя догадка:  5,2 м                                   |
|                                                         |
|                     [ ЗАФИКСИРОВАТЬ ]                  |
+---------------------------------------------------------+
```

После нажатия "Зафиксировать":

```
+---------------------------------------------------------+
|  Раунд 3                  Сердца: 4/5       Время: 18   |
|                                                         |
|  Твоя догадка:  5,2 м   (зафиксировано)                 |
|                                                         |
|          Ждём остальных игроков... 2 / 4 готовы         |
+---------------------------------------------------------+
```

- Ввод догадки - **только ползунок**. На нём нет делений и множителей,
  только "меньше" и "больше".
- Когда двигаешь ползунок, загадочная картинка меняет размер прямо рядом с
  эталоном.
- Под ползунком видна догадка в **метрах**.
- Ответ можно зафиксировать **раньше конца таймера**, после этого игрок
  ждёт остальных.
- [Предложение] Зафиксированный ответ поменять нельзя.
- [Предложение] Внутри ползунок работает логарифмически: движение в начале
  и в конце одинаково заметно и для муравья, и для небоскрёба. Игрок этого
  не видит.

### 2.4 Раскрытие ответа [Решено]

Когда все зафиксировали ответ (или время вышло):

1. Перед каждым игроком появляется его догадка - картинка того размера,
   который он выбрал.
2. В центре стола появляется настоящий объект в реальном размере.
3. Рядом с каждой догадкой (не над головой игрока) появляется процент
   точности, например "87,52%".
4. **Худшая** догадка теряет одно сердце. У **лучшей** догадки ничего не
   происходит - она просто выигрывает раунд.

- [Предложение] Каждому игроку свой цвет, и его догадка окрашена в этот
  цвет, чтобы сразу было видно, чья она.

## 3. Ход раунда [Решено]

```
 Стол заполнен -> Отсчёт -> Начало раунда -> Угадывание -> Раскрытие
                                  ^                             |
                                  |                             v
                                  +--- следующий раунд <--- Сердца + выбывание
                                                                |
                                         остался один игрок --> Конец матча
```

| Фаза           | Длительность | Что происходит                                   |
|----------------|--------------|--------------------------------------------------|
| Начало раунда  | 3 с          | Показываются названия эталона и загадки          |
| Угадывание     | до 30 с      | Игроки двигают ползунок и фиксируют ответ        |
| Раскрытие      | 5 с          | Догадки у каждого игрока, настоящий размер, %    |
| Итог раунда    | 2 с          | Худшая догадка теряет сердце, выбывания          |

- Угадывание длится **30 секунд**.
- Если все зафиксировали ответ раньше, раскрытие начинается сразу, не
  дожидаясь конца таймера.
- Если игрок не успел зафиксировать ответ, засчитывается положение ползунка
  в момент, когда таймер дошёл до нуля.

---

## 4. Как измеряется точность [Решено]

Точность показывается **в процентах с двумя знаками после запятой**.
Максимум - 100,00%. Считается она как отношение меньшего числа к большему,
поэтому ошибка "в 2 раза больше" и "в 2 раза меньше" наказывается
одинаково.

```
точность = меньшее(догадка, ответ) / большее(догадка, ответ) x 100%
```

| Настоящая высота | Догадка | Точность |
|------------------|---------|----------|
| 5 м              | 5 м     | 100,00%  |
| 5 м              | 4,99 м  | 99,80%   |
| 5 м              | 4 м     | 80,00%   |
| 5 м              | 10 м    | 50,00%   |
| 5 м              | 2,5 м   | 50,00%   |
| 5 м              | 0,5 м   | 10,00%   |

## 5. Победа в раунде [Решено]

- Очков нет.
- Раунд выигрывает игрок с **самой высокой точностью**.
- Матч выигрывает тот, у кого последним остались сердца.

---

## 6. Система выбывания - сердца [Решено]

### Стол 1 на 1

- У каждого игрока **5 сердец**.
- В каждом раунде игрок с **меньшей точностью** теряет 1 сердце.
- 0 сердец = проиграл матч.

### Стол на 4 игрока

- У каждого игрока **4 сердца**.
- В каждом раунде игрок с **самой низкой точностью** среди оставшихся
  теряет 1 сердце. У остальных ничего не меняется.
- 0 сердец = выбыл; дальше смотрит матч как зритель.
- Раунды продолжаются, пока не останется один игрок.

### Ничьи [Открыто]

- Одинаковая точность у худших - сердце теряют все, у кого она самая
  низкая.
- В 1 на 1 при одинаковой точности сердце не теряет никто.
- Если из-за ничьей все оставшиеся игроки потеряли бы последнее сердце
  одновременно, сердца не снимаются, и играется дополнительный раунд.

## 7. Библиотека объектов

Все объекты - **2D-картинки** [Решено].

Каждая запись об объекте содержит [Предложение]:

| Поле             | Пример                               |
|------------------|--------------------------------------|
| Название         | "Жираф"                              |
| Картинка         | id 2D-картинки, загруженной в Roblox |
| Настоящая высота | 5,2 (метра)                          |
| Категория        | Животные                             |
| Сложность        | Лёгкая / Средняя / Сложная           |

- На сцене картинка показывается на плоской панели (Part с Decal или
  SurfaceGui с ImageLabel). При изменении размера пропорции картинки
  сохраняются.
- [Предложение] Картинки - одноцветные силуэты, как в Size It Up. Тогда
  догадку каждого игрока легко покрасить в его цвет (раздел 2.4).
- Эталонные объекты - небольшой постоянный набор, который все знают (дверь,
  аватар Roblox, машина, дом). Игра выбирает эталон, не слишком далёкий по
  размеру от загадочного объекта, чтобы оба помещались на сцене.

## 8. Технические компоненты (Roblox) [Предложение]

### 8.1 Где что находится

| Место                 | Компонент              | Задача                                            |
|-----------------------|------------------------|---------------------------------------------------|
| Workspace             | Столы (Seats, сцена)   | Настоящие столы, за которые садятся игроки        |
| Workspace             | Панели на столе        | Центр: эталон и ответ; у каждого места: догадка   |
| ServerScriptService   | TableManager           | Видит заполненные столы, запускает/отменяет матч  |
| ServerScriptService   | MatchController        | Ведёт матч: раунды, таймер, досрочное раскрытие   |
| ServerScriptService   | ScoringModule          | Точность в %, победитель и худший в раунде        |
| ServerScriptService   | EliminationModule      | Сердца, выбывания                                 |
| ServerScriptService   | CashModule             | Наличные за победу (раздел 9)                     |
| ServerScriptService   | ObjectLibrary          | Список картинок с настоящими высотами             |
| ServerScriptService   | DataService            | DataStore: победы, наличные, таблица лидеров      |
| ReplicatedStorage     | RemoteEvents           | Сообщения клиент <-> сервер                       |
| StarterPlayerScripts  | GuessUI                | Ползунок, кнопка фиксации, таймер, сердца         |
| StarterPlayerScripts  | StageView              | Камера + изменение размера своей догадки          |

### 8.2 Сообщения (RemoteEvents)

| Событие        | Направление      | Что передаёт                                     |
|----------------|------------------|--------------------------------------------------|
| RoundStart     | сервер -> клиент | Название/высота эталона, id картинки загадки     |
| SubmitGuess    | клиент -> сервер | Догадка в метрах                                 |
| LockedInCount  | сервер -> клиент | Сколько игроков уже зафиксировали ответ          |
| RoundReveal    | сервер -> клиент | Настоящая высота, догадки и проценты всех        |
| StateUpdate    | сервер -> клиент | Сердца каждого игрока, кто выбыл                 |
| MatchEnd       | сервер -> клиент | Победитель, полученные наличные                  |

### 8.3 Защита от читов

- Настоящие высоты хранит **сервер**; клиент получает настоящую высоту
  только в `RoundReveal`, после окончания угадывания.
- Догадки соперников тоже приходят только в `RoundReveal`.
- Загадочная картинка показывается сначала в нейтральном размере, чтобы
  начальный размер ничего не подсказывал.
- Сервер игнорирует догадки, пришедшие после таймера, повторные догадки
  после фиксации и догадки от игроков, которые не сидят за этим столом.

### 8.4 Особые случаи

- Игрок вышел посреди матча -> считается выбывшим; если остался один игрок,
  он побеждает.
- Игрок вышел во время угадывания -> остальные не ждут его для досрочного
  раскрытия.
- Никто не зафиксировал ответ -> берётся положение ползунка на момент конца
  времени.

## 9. Награды и идеи на потом

### Наличные (Cash) [Решено]

Победитель матча получает наличные. Чем точнее он угадывал по сравнению с
соперниками, тем больше наличных.

[Предложение] Формула:

```
наличные = 50 + (средняя точность победителя - средняя точность соперников) x 5
```

"Средняя точность" - среднее всех процентов игрока за матч.

| Средняя точность победителя | Средняя точность соперников | Наличные |
|-----------------------------|-----------------------------|----------|
| 85%                         | 80%                         | 75       |
| 90%                         | 70%                         | 150      |
| 95%                         | 55%                         | 250      |

### Идеи на потом (не в первой версии) [Предложение]

- Наличные тратятся на скины ползунка / эффекты мест / цвета силуэтов.
- Тематические наборы объектов (животные, здания, космос).
- Рейтинговые столы с уровнем мастерства.
- Приватные столы с кодом приглашения.

## 10. Решения

### Принято

1. Ползунок - без множителей, только "меньше" / "больше".
2. Точность - в процентах, до 100,00%, с двумя знаками после запятой.
3. Проценты видны рядом с догадкой каждого игрока, а не над головой.
4. Все видят догадки всех; худшая теряет сердце, лучшей ничего не будет.
5. Сердца: 1 на 1 - 5 сердец, 4 игрока - 4 сердца.
6. Очков нет - только победа в раунде.
7. Объекты - только 2D-картинки.
8. Ввод догадки - только ползунок.
9. Единицы - метры.
10. Время угадывания - 30 секунд, можно зафиксировать ответ раньше и ждать
    остальных.
11. Наличные за победу - зависят от того, насколько точнее соперников.
12. Рабочее название - "Guess Its Size" (можно поменять позже).
